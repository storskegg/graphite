# Code of conduct

graphite follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and patient, assume good faith, and keep criticism about
the work rather than the person. Harassment of any kind is not tolerated.

Report unacceptable behaviour privately to the maintainer,
[@storskegg](https://github.com/storskegg), through a
[private security advisory](https://github.com/storskegg/graphite/security/advisories/new)
if nothing else fits. Reports are handled confidentially. The maintainer may
remove comments, code or contributors that break this code.
