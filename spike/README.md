# graphite-spike

The throwaway app that answered graphite's feasibility questions on real phones.
It is not part of graphite and is not shipped. The questions, results and
how to run it are in [docs/spike.md](../docs/spike.md).

It asks for SMS, call-log and all-files access and can take the SMS role. If
you install it, give the role back and uninstall it afterwards.
